## Sistemas de pedidos para restaurante/lanchonete

Nesse projeto nós vamos criar um sistema de pedidos e gerenciamento de estoque com funcionalidades como:
* Visualização de cardápio
* Seleção de produtos
* Adição e remoção de itens do pedido
* Calculo valor total
* Confirmação do pedido
* Geração da comandas para impressão
* Organização dos pedidos para o responsável pelo preparo
